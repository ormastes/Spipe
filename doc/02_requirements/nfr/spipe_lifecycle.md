# Lifecycle nonfunctional requirements

- NFR-001: SDN is canonical on disk; JSON is explicit interoperability. Closed versioned schema readers reject unknown fields/versions rather than guessing.
- NFR-002: Source revision, executable digest, policy digest and input/evidence dependencies bind each receipt. Only checked receipts affect gate state; human assertions are not tool evidence.
- NFR-003: Bound iterations, file/byte/depth reads, token/time and memory per role. Measure baselines before setting numeric performance admission thresholds; no invented performance PASS.
- NFR-004: Immutable evidence and parent-authoritative state commits; no silent overwrite, waiver or irreversible mutation. Private scopes and confidential dumps are denied before lookup.
- NFR-005: No competing scheduler, release admission implementation, knowledge authority or parser. Reuse host facilities behind explicit ports, retain compatibility aliases, and disclose reduced review independence.
- NFR-006: Pure-Simple domain code. Qualify actual compiler/test executable identities; a missing admitted runner yields TEST_BLOCKED, never a seed fallback or fabricated red/green result.
