# SPipe knowledge-system documentation

## Must know

Knowledge has common, company, organization, project, user, and host ownership
scopes. Registration does not copy content or grant access. Lifecycle documents
remain canonical. The current workspace and migration contract is recorded in
the [2026-09-09 research artifact](research/spipe_workspace_ownership_llm_wiki_2026-09-09.md).

## Exceptions

Machine paths and personal preferences are local configuration, not canonical
knowledge. Cross-scope publication always requires owner review.

The top-level `wiki/`, `raw/`, and `skills/` indexes are compatibility-aware
common-scope entrypoints. This directory remains documentation about the
knowledge system; it is not renamed wholesale into `wiki/`.
