# SPipe knowledge

## Must know

Knowledge has three ownership scopes: reusable common SPipe content, optional
organization content, and one or more project scopes. Registration does not
copy content or grant access. Lifecycle documents remain canonical.

## Routes

- [Local ownership and setup](local_ownership_setup.md)
- `../skill_command/skills/pipe/knowledge_ownership/skill.md` — authoring skill

## Exceptions

Machine paths and personal preferences are local configuration, not canonical
knowledge. Cross-scope publication always requires owner review.
