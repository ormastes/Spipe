# SPipe knowledge ownership

1. Resolve the common, organization, or project owner before reading or editing.
2. Read the scope's `index.md`, then follow its evidence routes.
3. Change the smallest canonical lifecycle artifact; do not edit generated views.
4. Validate references, authorization, applicability, and confidentiality.
5. Refresh only dependent navigation and summaries.
6. Treat rebalancing as a proposal. Require owner approval for physical moves.
7. To contribute to common, create a sanitized independent artifact with public
   evidence; never publish private paths, identities, or provenance.

Setup commands and layout are documented in
`doc/00_llm_process/knowledge/local_ownership_setup.md`.
